# Bearbrick report

Єдиний дашборд аналітики Bearbrick: жовтень 2026 — підсумок місяця, листопад 2026 — по тижнях.

Сторінка: https://nastyaderkach-dev.github.io/bearbrick-report/

## Як внести новий тиждень (щопонеділка)

1. Відкрити `index.html` → олівець «Edit this file».
2. Знайти через Ctrl/Cmd+F `novWeeks` — там рядок на кожен тиждень листопада.
3. У рядку потрібного тижня замінити `null` на цифри:
   - `meta` — витрати Meta за тиждень, $ (Ads Manager);
   - `google` — витрати Google Ads, $;
   - `orders` — замовлення CORE (Shopify);
   - `sales` — чисті продажі, $ (Shopify);
   - `c2p` — оформлення → покупка, % (GA4).
   Числа — без пробілів, ком і знака $: `meta: 3650`.
4. Тексти: `events` — події тижня, `changes` — що змінили в рекламі, `result` — висновок. Текст — в одинарних лапках.
5. Внизу «Commit changes». Сторінка оновиться за 1–2 хвилини: графік, таблиця, картки і цифри місяця перерахуються самі.

## Інше

- Цифри жовтня — там само, в об'єкті `const D = {…}` (kpi, weeks, camps, mkts, cr тощо).
- Тексти висновків і рекомендацій — у самому HTML, знайти через Ctrl/Cmd+F.
- Новий місяць (грудень) — попросити Claude додати частину 3 за тим самим зразком.
